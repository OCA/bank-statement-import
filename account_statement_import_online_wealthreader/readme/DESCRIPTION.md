This module provides online bank statement import via
[Wealthreader](https://www.wealthreader.com), a **Payment Institution authorized by
the Bank of Spain** (Banco de España).

Wealthreader is a powerful Open Banking aggregation service that goes far beyond
traditional providers. Key advantages:

- **14 geographies worldwide** — not limited to Europe. See the full list of
  supported institutions at
  [wealthreader.com/supported-entities](https://www.wealthreader.com/supported-entities/).
- **Maximum transaction detail** — the API retrieves checking accounts and their
  transactions with the highest level of detail available from each bank.
- **Beyond current accounts** — Wealthreader also aggregates credit cards, loans,
  investments, insurance products, and more, giving you a complete financial picture.
- **Authorized Payment Entity** — Wealthreader is a licensed Payment Institution
  regulated by the Bank of Spain, ensuring the highest standards of security and
  compliance.
- **Simple API-key authentication** — no complex OAuth flows; just an API key and
  your bank credentials (which are tokenized after the first use for maximum
  security).
