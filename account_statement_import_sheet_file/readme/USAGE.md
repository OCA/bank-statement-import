To use this module, you need to:

1.  Get statement in TXT/CSV or XLSX from your online banking software
2.  Go to Odoo and and import the statement file, selecting
    corresponding format

You can also download a sample XLSX template based on your configured
mapping:

- From the **Statement Sheet Mapping** form, click the **"Download
  Template"** button in the header to get an XLSX file with the correct
  column headers.
- From the **Import Bank Statement** wizard, click **"Get Sample Import
  Template"** to access the template directly.
