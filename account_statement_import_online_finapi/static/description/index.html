Online Bank Statements: finAPI

PSD2-compliant bank account import for Germany and the EU

Automatically pull transactions from German and European bank accounts via finAPI's Open Banking Access API. Modelled after the OCA Ponto module, this add-on registers a new finAPI provider under the account_statement_import_online framework.

  • One-click finAPI user creation per provider.
  • Web Form 2.0 flow for PSD2-compliant account access.
  • Automatic pagination over the /transactions endpoint.
  • Auto-refresh of access tokens; deterministic duplicate-free imports.
  • PSD2 consent expiry tracking and renewal wizard.
