This module is a glue module between two modules:

- **account_statement_import_online** from
  `OCA/bank-statement-import <https://github.com/OCA/bank-statement-import>`__.
- **account_reconcile_oca** from
  `OCA/account-reconcile <https://github.com/OCA/account-reconcile>`__.

This module updates the accounting dashboard so that clicking
**Transactions** for a credit card opens the transaction reconciliation
view when the online provider's **Create Statement** option is disabled.
When the option is enabled, the existing Credit Statements behavior is
preserved.

Installation
============

This module will be installed automatically by Odoo if the
**account_statement_import_online** and **account_reconcile_oca**
modules are installed.

Configuration
=============

On the online bank statement provider, disable **Create Statement** to
make the credit card journal's **Transactions** button open transaction
lines directly. Leave the option enabled to open Credit Statements
instead.
