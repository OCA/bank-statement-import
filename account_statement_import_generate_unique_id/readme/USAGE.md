**Only enable this option for journals whose source provides no
transaction identifier.**

Identical transactions (same account number, date, payment reference,
amount, reference and partner name) can only be told apart within the same
import. If an import ends between two identical transactions of the same
day, the second one gets the same identifier in the next import and is
ignored as already imported. Therefore always import complete days, and do
not enable this option when such identical transactions are common and
statements may cover partial days.
