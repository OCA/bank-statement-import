Go to *Invoicing > Configuration > Journals*, open a bank journal and
enable *Generate Missing Import IDs*.

Only statement lines imported after enabling the option get a generated
import ID. To set it for the existing statement lines of the journal that
have none, click *Generate for Existing Lines* next to the option.
Lines whose generated import ID is already used by another line are
skipped and reported, as they may be duplicates. Check them manually.
