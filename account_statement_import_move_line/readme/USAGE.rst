Journal items can be imported either into a new bank statement or into an
existing one.

#. Go to Invoicing > Dashboard.
#. To import into a new statement, click on "Import Journal Items" in the
   options menu of the relevant bank journal. To import into an existing
   statement, open the statement form and click on the "Import Journal Items"
   button.
#. Select filtering options.
#. Click on button "Add All Move Lines" to auto-select the move lines matching
   the selected criteria or click on Add an item to manually select the move
   lines filtered by the criteria.
#. Click on button "Create Statement Lines".
