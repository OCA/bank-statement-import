To use this module, follow these steps:

1. Export your bank statement from your online banking software in **TXT**, **CSV**, or **XLSX** format.
2. In Odoo, go to **Accounting > Bank and Cash > Import Statement** and select the corresponding file format.
3. Click the **Import as Batch** button in the import statement wizard to process the file via queue jobs.
4. Review the **Bank Statement Import History** to monitor the status of the import and check for any notifications or errors.
